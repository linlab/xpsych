# Data and instrument boundaries

User-supplied item wording and keys enter through ItemBank. The installable package
includes the public-domain IPIP-50 Big-Five Factor Markers with their published
item wording and key signs. The offline example simulates activities; the text
example uses illustrative narratives. Neither example supplies participant data.
Other instrument banks must be supplied under their own terms.
The MIT code licence does not grant rights to any questionnaire or source dataset.

The COMPASS 2.0 folder includes aggregate reference results, public symptom inputs,
public RDoC definitions, ordered item keys and input schemas. It excludes participant
transcripts, questionnaire responses, licensed WAI wording and model weights.
Exact prepared instrument banks must be obtained through an authorized route; a
schema filled with different wording will not reproduce the paper.

DAIC-WOZ/E-DAIC and Alexander Street inputs require their respective access
arrangements. The reproduction README explains expected paths. Keep inputs,
models, row-level derivatives and caches outside version control. These locations
are ignored by default in each paper folder. Aggregate reference JSONs are included
for numerical comparison; they are not evidence of a new run on raw data.

IPIP item and scale permissions are stated at https://ipip.ori.org/ .
The 50-item key is at https://ipip.ori.org/newBigFive5broadKey.htm .
The package groups items by construct; use bank.ids rather than assuming the
interleaved order of a questionnaire form.
